# Machine Learning module (next development stage)

This folder is reserved for the real ML systems used by DATA SIEGE. Planned modules:

- `preprocessing.py`: missing values, duplicate rows, encoding and scaling.
- `classification.py`: supervised classifier trained on labelled examples.
- `decision_tree.py` and `knn.py`: Campaign 2 algorithms.
- `clustering.py`: K-means unsupervised learning.
- `regression.py`: continuous-value prediction.
- `evaluation.py`: confusion matrix, accuracy, precision, recall and overfitting checks.

These are not yet connected to the battle prototype. The next milestone is to make Campaign 1 train and test a real classifier and use its predictions in battle.
